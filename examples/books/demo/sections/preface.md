# ТРОПА СТЕКЛЯННОЙ ДОЛИНЫ

Книга-игра для примера

# ПРАВИЛА ИГРЫ

##### ЛОВКОСТЬ, СИЛА И ЧЕСТЬ

Бросьте два кубика: по сумме из таблицы определяются ваши ЛОВКОСТЬ, СИЛА и ЧЕСТЬ. СИЛА не может стать больше начальной, а когда она упадет до нуля, путешествие окончено.

##### БОЙ

В каждом раунде киньте кубик за противника и за себя, умножьте на два и прибавьте ЛОВКОСТЬ. Чей удар сильнее, тот и ранит; рана отнимает 2 СИЛЫ. В поединке мыслей вместо ЛОВКОСТИ считается Сила мысли.

##### УДАЧА

Кубик брошен дважды, выпавшие числа зачеркнуты. Когда книга попросит проверить УДАЧУ, свободное число на кубике принесет успех.

Теперь переверните страницу.
